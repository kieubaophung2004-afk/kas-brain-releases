# KAS Brain — bản cài đặt

Repo này chỉ chứa **bộ cài đặt** KAS Brain cho Windows (mục *Releases*). Không có dữ liệu cá nhân nào ở đây — dữ liệu nằm trong thư mục OneDrive\KAS Brain trên máy.

- Tải bản mới nhất: **Releases → KAS-Brain-Setup-x.y.z.exe**
- App tự kiểm tra repo này và hiện nút **Cập nhật** ở góc dưới bên trái.
